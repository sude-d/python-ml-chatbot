# Python ML Chatbot 🤖

A simple chatbot project built with Python and machine learning.

## About

This project uses **TF-IDF** and **Logistic Regression** to classify user messages into different intents and generate appropriate responses.

The chatbot is trained with 200 English example messages covering topics such as:

- Python
- NLP
- NumPy
- Pandas
- Scikit-learn
- Machine Learning
- Artificial Intelligence
- Deep Learning
- Classification
- Regression

It also recognizes basic conversational intents such as greetings, asking about the chatbot, thanking and saying goodbye.

## Technologies

- Python
- Scikit-learn
- TF-IDF
- Logistic Regression
